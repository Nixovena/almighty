Release History

Version changelog and release announcements for Almighty Linux.

MAY 2026 — MAJOR RELEASE

Almighty Linux 1.0

Stable release with a unified Kali Linux base and significant tool updates.

  • Complete Structural Overhaul: Transitioned from a Debian/Kali hybrid to a pure Kali Linux base to eliminate conflicts and enhance stability.
  • New Custom OSINT Tools:
    • DescendSec: Advanced Discord reconnaissance tool.
    • mailbull: Python-based email intelligence module.
    • mrcrypt2: Next-gen crypto OSINT toolkit.
    • almighty-osint-ai: Advanced AI-powered research assistant.
  • Expanded External Arsenal: Added toutails, yesitsme, webbextractor, duolingosint, kalitorify, and openosint.
  • DeepChainTK Major Update:
    • OFAC Compliance: Live SDN control from 0xB10C feeds (BTC/ETH/USDT/XMR/LTC/BCH/XBT).
    • Enhanced Entity DB: Over 70 addresses including Tornado Cash, Lazarus, and various exchange clusters.
    • Advanced Analysis: Counterparty, Cluster (BTC), Timing (UTC heatmap), and PriceFeed (CoinGecko) analyzers.
    • Multi-Chain Support: Native Tron and XRP support via Tronscan/XRPScan APIs.
    • Web3 Intelligence: ENS Resolver and ERC-20 history tracking.
    • New Risk Heuristics: Dust attack and dormancy break detection.
  • Infrastructure & UI:
    • Almighty Panel: Various bug fixes and structural changes.
    • Almighty Fetch: Fixed ASCII system info display.
    • Usability Hardening: Security profiles relaxed for better performance while maintaining core protections.
  • Privacy & Web:
    • Almighty OSINT Browser: Enhanced privacy features and more built-in utilities.
    • New Firefox Instance: Pre-configured with uBlock Origin, OSINT-specific bookmarks, disabled telemetry, and hardened security.
